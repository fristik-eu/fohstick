# Changelog

## [1.0.0] – 2026-11-23

First public release of **FOHstick**.

**Convert**
- MP3, WAV, FLAC, AIFF, AAC/M4A → WAV 44.1 / 48 / 96 kHz, 16 / 24 bit, mono / stereo
- Batch conversion, drag & drop, originals kept

**Format**
- Presets for 13 console families (Yamaha, Behringer / Midas, Allen & Heath, Soundcraft, DiGiCo)
- Custom mode: FAT32 / exFAT / FAT16, cluster size, partition size
- FAT32 on drives larger than 32 GB (also on Windows)
- Only external drives listed, system disk protected

**App**
- macOS (Apple Silicon & Intel) and Windows 10 / 11
- Light / Dark / Auto theme
- Slovak / English, switchable live
- Console list and update check loaded from GitHub
